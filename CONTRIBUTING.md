# Contributing

Thanks for helping improve GitHub Repo Analyzer.

## Development setup

1. Clone the repo.
2. Install workspace dependencies.
3. Run the app with `npm run dev`.
4. Create a branch for your feature or fix.

## Pull request checklist

- Keep changes focused and well-tested.
- Add or update relevant tests.
- Update documentation if the behavior changes.
- Ensure the app still builds and passes lint/test checks.

## Coding standards

- Favor clear, maintainable code.
- Keep security and safe API handling in mind.
- Avoid introducing secrets into the project.

## Issues

Use the GitHub issue templates to report bugs or feature requests with reproduction steps.
