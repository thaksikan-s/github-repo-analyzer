# Security Policy

## Supported versions

The project is under active development. Security fixes will be prioritized for the latest main branch.

## Reporting a vulnerability

Please report vulnerabilities privately by opening a security advisory or contacting the maintainers directly through the repository’s private security reporting path.

## Disclosure expectations

- Do not publicly disclose a vulnerability before a fix is available.
- Provide reproduction details and impact assessment when possible.
- Avoid exposing secret tokens or user data in issue reports.
